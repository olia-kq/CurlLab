# CURL LAB — сайт салону кучерявого волосся

Багатосторінковий адаптивний статичний сайт українською з англомовними заголовками. Підготовлено для GitHub Pages.

## Публікація
1. Створіть публічний репозиторій на GitHub.
2. Завантажте **вміст** цієї папки до кореня репозиторію (файл `index.html` має бути в корені).
3. У GitHub відкрийте **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Оберіть `main` та `/ (root)` і натисніть Save.
5. Після публікації GitHub покаже URL сайту.

## Важливо
- Форма запису — **демонстраційна**, без сервера, реальних бронювань, передоплати чи збереження заявок.
- Профілі майстрів, відгуки та фотографії — ілюстративні. Не слід видавати їх за справжніх співробітників, клієнтів чи результати салону.
- Адреса, телефон, соціальні мережі та графік не вигадані: їх можна додати, коли вони будуть відомі.
- Фотографії завантажуються з Unsplash Source images через `images.unsplash.com` та можуть вимагати підключення до інтернету. Перевірте ліцензії та право використання перед комерційним запуском.
- Для справжнього онлайн-запису потрібна CRM / серверна інтеграція та політика конфіденційності.
